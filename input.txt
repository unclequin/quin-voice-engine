Stop Thinking in RAM, Start Dumping to Disk — เมื่อไหร่ที่รู้สึกเครียดหรือคิดวนซ้ำ ๆ แปลว่า Working Memory ในหัวคุณเต็มแล้ว หยุดพยายามคิดต่อในหัว แล้วดึงมันออกมาเขียนลงกระดาษหรือโน้ตทันทีค่ะ
Separate Event from Emotion — แยก "เหตุการณ์ที่เกิดขึ้นจริง (Immutable Event)" ออกจาก "อารมณ์ที่ปรุงแต่ง (Mutable State)" เพื่อให้เรามองเห็นจุดที่ต้องแก้ไขได้โดยไม่หลอกตัวเองค่ะ
Debug from the Third-Person View — ถอยออกมาหนึ่งก้าวเพื่อมองดูความคิดและปัญหาของตัวเองเหมือนดูความทรงจำในอ่างเพนซิฟ เมื่อเราไม่เอาตัวตนไปผูกติดกับปัญหา เราจะเห็นทางออกที่ซ่อนอยู่เสมอค่ะ
