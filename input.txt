Speaker 2: ภาพของมิติ Limbo ในหนัง Inception นี่แหละครับฟ้า คือฝันร้ายคลาสสิกที่สุดของโปรแกรมเมอร์ทุกคน เวลาที่เราเขียนฟังก์ชันแบบ Recursion แล้วเราลืมเขียนเงื่อนไขการหยุด หรือที่เราเรียกว่า Base Case!

Speaker 2: ในหนัง Inception การดีดตัวกลับขึ้นมาจากความฝันทีละชั้น ก็คือการใช้จังหวะกระตุกตกจากที่สูงพร้อมเสียงเพลงปลุก หรือที่ในหนังเรียกว่า "The Kick" นั่นเองครับ...
แต่ถ้าเมื่อไหร่ที่เราเขียนโค้ดให้ฟังก์ชันเรียกตัวเองดำดิ่งลงไปเรื่อย ๆ โดยไม่มี Base Case คอยสั่งให้ดีดตัวกลับ หรือลงไปลึกเกินกว่าที่พื้นที่หน่วยความจำจะรับไหว สิ่งที่จะเกิดขึ้นก็คือวิกฤตที่ชื่อว่า Stack Overflow ครับ! ระบบจะพังทลายลงมาทันที เพราะมันหลงทางอยู่ในชั้นที่ลึกเกินไปจนจำทางกลับขึ้นไปหาโลกความจริงที่ชั้นบนสุดไม่ได้อีกต่อไป เหมือนคนที่ติดอยู่ใน Limbo จนแยกไม่ออกว่าอันไหนคือความจริง อันไหนคือความฝันครับ

Speaker 1: เปรียบเทียบเรื่อง The Kick กับการคืนค่ากลับขึ้นมาจาก Call Stack และ Limbo กับ Stack Overflow ได้เห็นภาพชัดมากเลยค่ะลุงควิน!

Speaker 2: โอ้โห ฟ้าพูดถูกจุดที่สุดเลยครับ! ในทางวิศวกรรมซอฟต์แวร์ เรามีสิ่งที่เรียกว่า Abstraction Layers หรือ "ชั้นของการซ่อนความซับซ้อน" ครับ
ในหนัง Inception มีตัวละครสำคัญคนหนึ่งชื่อว่า "แอรีแอดเน" ซึ่งรับบทเป็น "สถาปนิกแห่งความฝัน" หน้าที่ของเธอคือการออกแบบตึก ถนนหนทาง และเมืองจำลองที่ดูสวยงามสมจริง เพื่อให้นักฝันเดินเข้าไปใช้งานได้ง่าย ๆ โดยที่คนในฝันไม่ต้องมานั่งคิดเลยว่าอิฐแต่ละก้อนหรือแรงโน้มถ่วงในฝันมันถูกคำนวณขึ้นมาจากสมองส่วนไหน

Speaker 2: ในโลกคอมพิวเตอร์ก็เหมือนกันเป๊ะเลยครับ ย้อนกลับไปเมื่อห้าสิบปีก่อน โปรแกรมเมอร์ทำงานอยู่บน "โลกความจริงชั้นบนสุด" นั่นคือการคุยกับฮาร์ดแวร์โดยตรง เขียนคำสั่งจัดการหน่วยความจำทีละไบต์ สั่งงานซีพียูผ่านภาษาเครื่องและ Assembly... แต่มันยากและเหนื่อยมากครับ มนุษย์เราเลยค่อย ๆ สร้าง "ชั้นความฝัน" หรือ Abstraction Layer ซ้อนทับลงไปทีละชั้นเพื่อให้ชีวิตง่ายขึ้น:
ชั้นที่ 1: เรามีระบบปฏิบัติการ และภาษาระดับสูงที่จัดการหน่วยความจำให้เราอัตโนมัติ
ชั้นที่ 2: เราเอาไลบรารีและ Framework ขนาดใหญ่มาครอบทับลงไป จนบางทีเราเขียนโค้ดแค่บรรทัดเดียว ข้างหลังมันแอบไปรันคำสั่งเป็นพันบรรทัดโดยที่เราไม่รู้ตัว
ชั้นที่ 3: เราเอาโค้ดนั้นไปใส่ไว้ใน Container อย่าง Docker
ชั้นที่ 4: เราเอา Container ไปรันอยู่บนระบบจัดการอย่าง Kubernetes
ชั้นที่ 5: ซึ่ง Kubernetes นั้นก็รันอยู่บน Virtual Machine หรือเครื่องคอมพิวเตอร์จำลอง ที่เช่าอยู่บนระบบ Serverless ของ Cloud อีกต่อหนึ่ง!
